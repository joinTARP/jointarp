# 界面设计

桌面界面采用简洁、现代的中性色设计。基础组件集中在 `apps/desktop/src/renderer/src/components/ui/`，Button、Input、NumberInput、Select、Tabs、Dialog、Tooltip 和 Form 使用 Base UI 原语，Textarea 使用原生元素。组件层负责视觉规则，业务层负责内容与布局。

## 桌面交互

三平台共用视觉规则，系统菜单、编辑快捷键和窗口操作遵循平台惯例。应用菜单由 Electrobun 提供，文本编辑右键菜单使用系统 WebView，业务操作菜单使用 Base UI。设置快捷键为 `CmdOrCtrl+,`，由主进程经过原生桥的单向事件打开当前窗口的设置层；没有窗口时从设置页重建主窗口，不注册系统全局快捷键。

Windows 使用 36px 高的主题标题栏，左侧仅显示 TARP 品牌，不提供传统菜单栏或折叠菜单按钮；右侧保留最小化、最大化或还原、关闭按钮；关闭悬停使用系统习惯的红色。标题栏独立占据布局空间，模组、设置、对局和参考窗口共用，不遮挡正文与弹窗。标题区域可拖动与双击缩放，按钮排除在拖动区域之外；应用快捷键在窗口内处理，编辑快捷键继续交给 WebView。

主导航、对局视图、模组正文和设置分区直接切换内容，全屏设置直接打开与关闭，不使用正文淡入淡出或 View Transition 快照。切换时保留已有持久布局和已挂载内容状态；菜单选中背景共用 `components/NavigationMotion.tsx` 的 `NavigationMotion` 和 `NavigationHighlight`。

## 交互反馈与表单

按钮、菜单、导航和可操作卡片使用箭头指针，正文链接与行内文档引用保留手形。控件、导航、标签和装饰文字不支持文本选择；输入、聊天、文档和错误信息保留复制能力，控件内需要复制的内容使用 `data-copyable`。封面、头像等界面图像不启用浏览器默认拖拽，正文内容不做全局拖拽拦截。保留现有系统窗口、弹窗、滚动条、资料预览和中文输入行为，不注册全局鼠标保焦或禁止选择的监听器。

不使用 HTML `title` 提供应用提示。普通操作说明使用 Tooltip，默认悬停 500ms 后出现，相邻提示可连续查看；键盘聚焦可查看，Esc 关闭。Tooltip 不增加布局节点，通过 Base UI 的组合能力保留按钮、菜单、预览卡和弹窗触发器的事件与引用。可操作内容使用预览卡或详情入口，错误、缺失引用与禁用原因在界面中提供可见说明。名称补全提示启用 `overflowOnly`，仅实际溢出时出现；图标按钮使用独立的 `aria-label`。消息时间保留完整时间提示与键盘入口。

提交型表单使用 Form、Field 与 FieldError，首次提交时显示字段错误并聚焦第一个错误字段，之后随输入更新校验结果。不使用浏览器默认校验气泡；其他表单保留业务校验并设置 `noValidate`。自动保存字段按各自的业务规则保存和校验。

数值输入使用 NumberInput，保留清空、负数、小数和输入中间态，范围由业务定义；数量项使用 `quantity` 提供增减按钮，其他数值项不显示步进按钮。滚轮继续滚动页面，不直接修改数值。数量项在完成输入时按范围与整数格式处理，通用字段不主动推断模组的合法范围。

## 色彩与控件形态

模组封面素材采用横向 16:9，模组列表与冒险缩略图保持此比例。首页冒险主视觉使用 240px 高的横幅，准备大厅封面高度随视口变化并限制在 180–320px，避免全宽图片撑高页面。图片居中等比填满容器，超出部分裁切；加载占位、缺图与加载失败时的回退保留容器尺寸。

亮暗主题共用 `styles.css` 中的语义令牌。背景、面板、边框和主操作使用黑白灰，通过明度区分层级；危险操作保留红色，文档链接保留独立颜色。新增基础组件使用这些令牌，不单独写一套亮暗色值。

主按钮、次按钮和描边按钮使用胶囊形态，图标按钮为圆形；普通文字工具按钮采用小圆角。普通单行和多行输入统一使用 8px 小圆角、浅灰填充与内边距，默认隐藏边框。只有聊天 composer 的输入容器使用 16px 大圆角，内部文本区域保持透明，不额外形成圆角输入框。键盘聚焦时只显示细边界，不使用外扩光圈；错误状态保留红色边界。按钮键盘聚焦使用带间距的轮廓，禁用态不能只靠颜色差异表达。

桌面控件保留紧凑密度，按钮高度分别为 24、28、32、36px，默认输入框高 36px，多行输入最小高度为 80px。按钮与输入框的状态变化只过渡颜色，遵循系统减少动态效果设置。

业务中的侧栏导航、模型选项、房间开关和工具操作使用 1px 键盘焦点轮廓，不叠加外扩 ring 或 ring-offset 光圈。卡片键盘聚焦使用细边框和内侧轮廓；主题与文档卡片的选中态使用边框、背景和勾选标识，不增加常驻外圈。基础 Button 与 Tabs 使用各自的键盘焦点提示。角色字段的布尔、枚举与引用选择统一复用 Base UI Select，保留空值清除选项。

带文字的按钮根据直接子级图标的位置调整留白：前置图标侧减少 2px 左留白，后置图标侧减少 2px 右留白；双侧图标分别补偿，纯文字保持对称。图文默认间距为 6px，最小按钮为 4px，内容使用紧凑行高居中。纯图标尺寸变体使用零内边距与零间距，图标在固定方形点击区域内居中；图标应直接放在 Button 下，尺寸由组件默认值或图标的 size 类决定。

Select 触发器与普通输入框统一使用 8px 小圆角和灰色填充，包括 composer 内的提交方式选择器；默认列表从触发器下方展开。列表使用 16px 圆角、轻边界和阴影，选中项保留勾选标识，键盘高亮使用独立背景。紧凑触发器高 28px，默认高 36px。

Tabs 默认使用灰色胶囊轨道，当前项采用主色填充与反色文字，不使用卡片阴影；正文内导航可使用细线变体。横向与纵向布局共用 Base UI 的方向状态，指示器移动遵循减少动态效果设置。

## 聊天输入与草稿

Composer 的焦点反馈由外层容器承担，只改变细边框颜色；聚焦不增加外扩光圈、不加深阴影，也不移动容器。内部文本区域不单独显示焦点边界，工具按钮仍保留各自的键盘焦点反馈。

连续输入时，若输入框已聚焦，鼠标点击发送、继续、停止生成、聊天／行动模式和语音工具会保留文本焦点与选区。执行发送、继续、继续开场和重试发送时，焦点回到文本区域；聊天／行动模式、停止生成和语音工具通过键盘操作后遵循控件自身的焦点行为。提交方式列表使用 Base UI 默认焦点恢复，选择或按 Esc 关闭后回到触发器；点击列表外的其他控件时遵循正常焦点行为。发送请求完成时不再次聚焦，以免打断用户在其他输入框或弹窗中的操作。

聊天页可见、首屏日志就绪且进入遮罩已撤下时，自动聚焦 composer；准备大厅、隐藏的聊天页和其他页面不启用直接输入。点击非编辑区域后，开始输入文字、使用中文输入法或通过快捷键粘贴时转回 composer，由浏览器继续处理当前输入。其他输入框、可编辑内容、选择器、菜单和弹窗保留自己的键盘行为；@ 候选属于 composer，不阻止继续输入。Esc、Tab、Enter、方向键、按钮与链接的空格激活，以及粘贴以外的系统快捷键不重定向。Shift+Tab 在聊天输入框及聊天页非编辑区域切换模式，优先于 @ 候选；普通 Tab 仍选择候选。IME 组字、其他编辑控件和弹层保留原行为。模式切换保留草稿和选区；合法 @ 自动归为聊天，界面同时显示手动偏好与自动用途。点名编辑采用纯文本与不可拆分的身份标签；发送时仅传含身份链接的 Markdown 正文；候选选择和手写完整链接均按同一规则判断点名，主机校验后生成 mentions 记录。复制时同时保留纯文本名称与应用内身份数据。不注册全局鼠标保焦监听，也不监听失焦或网络响应强制抢回焦点。

@ 候选列表按 Esc 仅关闭候选，输入框继续保持焦点；角色右侧栏按 Esc 关闭后回到展开按钮；普通弹窗与菜单使用 Base UI 默认焦点恢复；文档详情弹窗打开时聚焦内容容器，关闭时不自动恢复焦点。关闭弹层后若焦点回到非编辑控件，开始输入文字时可以继续在 composer 编辑。

发送请求开始时清空未改动的当前草稿，用户可以立即撰写下一条；请求成功后不再清空草稿。发送失败且尚未开始新草稿时恢复原输入；已有新草稿时保留新内容，失败消息另行提供重试入口。

## 弹窗与焦点恢复

Dialog 使用正文页面的 `background` 和 `foreground` 令牌，亮色底为 `#fafafa`、暗色底为 `#171717`；下拉菜单独立使用 `popover` 令牌。弹窗使用 24px 圆角和内边距，标题、正文与操作区通过留白区分，不增加底部分隔色块。弹窗与遮罩仅淡入淡出，最大高度受视口约束；复杂页面可按需覆盖内容布局与滚动方式。

嵌套弹窗逐层渲染独立遮罩，通过 Base UI Backdrop 的 `forceRender` 启用。每层遮罩对下面的页面与弹窗叠加 2px 背景模糊和半透明压暗，当前弹窗保持清晰；关闭时逐层淡出并恢复下层焦点，不直接给父弹窗添加模糊滤镜。

对局页面收到桌面的退出请求事件后打开确认弹窗，由页面状态控制开关。取消通过 DialogClose 关闭，焦点恢复交给 Dialog；确认退出后返回首页，冒险保持进行中。

## 文档容器与侧栏

### 详情弹窗

文档详情弹窗仅保留屏幕阅读器所需的隐藏标题和说明，不渲染固定标题栏。普通详情的封面、名称和各区块由 `DefaultDocumentLayout` 生成并随正文滚动，自定义 HBS 模板自行安排名称和图片。双栏详情保留内容留白，左右栏由 `DocumentDetail` 分别提供滚动区；窄窗口上下排列，空栏不占位。`columns` 控制普通详情或双栏左侧的属性列数，双栏右侧内容纵向排列，避免长文被压缩到半栏。嵌入页面的详情使用页面自身滚动。

`detail.width` 在 grid、split 和 Handlebars 三种详情配置中独立校验并保留到运行时布局。`DocumentDialog` 将其用于弹窗外部宽度，宽度不超过视口扣除两侧留白后的空间；未配置时，普通详情默认最大宽度为 800 像素，双栏详情为 1000 像素。嵌入详情不读取该值，模板排版也不把期望弹窗宽度作为固定内部宽度。`sheet.width` 独立控制角色卡宿主。

### 角色卡侧栏

游戏右侧面板由 `GameSidebar` 承载，期望宽度取自当前玩家角色类型的 `layout.sheet.width`，未配置时使用 360 像素。宿主观察游戏壳容器宽度；剩余空间不足以保留聊天区域及展开的左侧栏时，切换为右侧模态抽屉，抽屉宽度不超过视口。侧栏按作者设定的固定宽度显示，不维护拖动调整状态，也不提供鼠标或键盘调整手柄。关闭后焦点回到触发器；抽屉通过现有 Dialog 实现遮罩、焦点约束和 Esc 关闭。嵌入卡片、普通详情与悬浮的容器不读取该宽度。

## 设置与自动保存

桌面默认配置由 `GameDefaultsForm` 组合四个页签，房间配置由 `RoomConfigurationForm` 按分区组合主持指令、语音、上下文订阅、新增队友模板和队友扮演指导；公共字段不判断页面模式。`useGameConfiguration` 统一管理保存、失败重试、模型选择和试听生命周期。`AutosaveScope` 在页签切换、文本编辑器关闭和设置退出前提交已注册字段，失败时保持当前界面与草稿。`ConfigurationSaveStatusProvider` 汇总选择项和文本字段的保存状态，错误优先；文本编辑器复用 `AutosaveField`，卸载前必须提交成功。按条件收起区块时，只隐藏界面，不清除已保存的配置。

## 组件维护

基础组件自行维护样式与业务所需变体，复杂交互由 Base UI 提供。优先复用原语的键盘、焦点、弹层和状态能力，不在业务代码中重复实现同名控件。

`Button` 的变体、尺寸与 `buttonVariants` 入口统一维护，导航链接可以复用按钮样式。调用方通过 `className` 调整具体布局与尺寸。

状态样式直接引用 Base UI 的 `data-*` 属性，不引入跨原语库的状态别名或 shadcn 样式入口。弹层进入和退出通过 `data-starting-style`、`data-ending-style` 控制，焦点恢复和关闭时机由 Base UI 管理。不使用 shadcn CLI 覆盖自有组件。

视觉改动验证亮暗主题、悬停、按下、键盘焦点、禁用和错误状态，并检查真实页面中的长文本与图标布局。仅样式调整不新增绑定 CSS 类的测试，复用已有界面场景；测试原则见[测试维护](测试维护.md)。
