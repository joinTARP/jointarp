# 互联网联机诊断

桌面主进程的联机错误按建立连接的阶段保留诊断信息。相关实现位于 `apps/desktop/src/main/online/`，不改变协议版本或信令内容。

- 协调连接超时：WebSocket 尚未完成欢迎消息及初始化；错误包含协调服务地址。
- 等待房主协商超时：尚未收到可用的房主协商入口；错误包含协调服务是否在线及已记录的协调错误。
- 联机握手超时或对端连接断开：错误包含 P2P、ICE、候选收集状态，描述与候选的发送／接收数量，以及两个数据通道的开放进度。

描述未收到说明信令交换尚未完成。双方已有描述和候选但 ICE 未连接时，需要结合双方网络环境检查候选可达性，不能仅凭超时断言 NAT 类型。当前正式连接仅使用 STUN，不提供 TURN 中继；有候选不代表直连必然可达。通道未达到 `2/2` 时，RPC 与资源通道尚未全部就绪。

诊断不记录 SDP 原文、候选 IP、房间凭证或身份私钥。复现时应保留双方完整错误和发生阶段；本机回环测试只能验证实现，不能替代跨网络验证。
