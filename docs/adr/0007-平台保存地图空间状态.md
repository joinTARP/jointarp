# 平台保存地图空间状态

地图配置放在模组的 `maps/` 目录，使用平台固定格式，不进入作者自定义的文档类型系统。房间内角色所在地图与坐标、门状态和队伍探索记录由平台保存在独立的房间地图状态中，主持通过专用地图工具更新；模组自有的地点、时间与资源字段保持不变，由主持按模组规则同时维护。

这一选择修订 [ADR 0004](0004-模组解释玩法状态.md) 关于“位置由模组解释”的边界：平台只拥有几何意义上的空间位置、视野和遮挡，不解释地点归属、耗时、通行合法性或规则效果，也不自动安排入场。平台空间位置与模组地点字段可能短暂不一致，由主持裁定并修正，不建立自动双向同步。

地图状态按查看者投影后同步：主机按全队视野过滤，只下发当前可见的标记与探索记录，不把原始地图状态放入共享文档实体。底图、墙体和门等静态配置与现有 `public/gm` 字段处于同一本机信任边界，云端权限上线前统一处理。移动仍遵循 [ADR 0006](0006-地图移动由主持统一裁定.md)：玩家提交的移动意图只是预览，主持确认后才改变位置并揭示。
