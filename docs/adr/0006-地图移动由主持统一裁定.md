# 地图移动由主持统一裁定

地图交互提交移动意图，由主持按模组规则统一结算实际位置、游戏耗时和途中事件，随后地图更新位置与探索表现；等待期间的目标和路线仅为预览，不改变真实位置或提前揭雾。多人行动共同结算，避免把同时发生的行动耗时简单累加。

这一边界牺牲直接拖动即时生效的体验，以避免 AI 处理延迟导致角色先越过事件点、随后回退并泄露未知区域。即便路线已经探索，移动仍可能消耗时间和资源并触发事件，因此首版不采用“已知路段自动结算、遇事再交主持”的方案。

本决策是后续地图功能的设计约束，尚未实现；延续 [ADR 0004](0004-模组解释玩法状态.md) 的模组解释规则边界，具体空间契约与首版规则覆盖范围仍在[设计讨论](../地图功能设计讨论.md)中澄清。
