# 开发文档索引

本目录集中维护开发环境、架构、工程实现、内部契约、扩展、恢复、测试和发布文档。workspace 结构、依赖安装与常用命令见[根 README](../README.md)，桌面启动、打包与局部约定见[桌面 README](../apps/desktop/README.md)。玩家指南和模组创作规范以官网文档为准，源码仓库不重复维护参数表或操作教程。

首次参与开发时，先按根 README 启动应用，再根据改动范围阅读下列实现文档；涉及持久化、同步或恢复时，同时核对存档和文件存储契约。

文中的完整源码路径以仓库根目录为基准；同一模块内的短路径相对该模块目录。命令从仓库根目录执行，另有说明时以指定工作目录为准。

## 文档维护

每项契约的完整说明放在对应主题中，其他文档通过链接引用。界面交互归入界面设计，存档字段与恢复边界归入存档格式，设计取舍归入 ADR；应用和包的 README 保留启动、构建及局部开发入口。

实现文档描述当前职责、行为、约束与验证方式。修改功能时直接更新对应章节，避免把不同主题的变更说明追加到文末；一次性验收数据、临时方案和测试结果不作为长期契约保留。影响使用或模组格式的变更同步修改官网正文。移动章节时同步维护索引和锚点链接。
